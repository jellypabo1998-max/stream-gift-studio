# Stream Gift Studio

เว็บเครื่องมือ TikTok LIVE ที่เขียนใหม่ด้วยหน้าตาและโค้ดของโปรเจกต์เอง ไม่ใช่ TikFinity และไม่เกี่ยวข้องกับ TikFinity หรือ TikTok

## ฟังก์ชัน
- ใส่ @username ที่กำลัง LIVE เพื่อรับคอมเมนต์ ผู้ติดตาม และของขวัญ
- เสียงอ่านภาษาไทยด้วยเสียงที่เบราว์เซอร์มีให้ เลือกเสียง ความเร็ว และความดัง
- เลือกเสียงติดตาม/ของขวัญแยกกัน หรืออัปโหลดไฟล์เสียง
- รูปและ GIF บนจอ ปรับขนาดและตำแหน่ง
- อันดับผู้ส่งของขวัญ ตามมูลค่าเหรียญ ไม่ใช่เงินบาท พร้อมรีเซ็ตแต่ละรอบ
- URL วิดเจตพื้นหลังโปร่งใสสำหรับ OBS Browser Source
- หน้าแต่ละเบราว์เซอร์แยกห้องกัน ลิงก์วิดเจตมีโทเคนเฉพาะห้อง
- กิจกรรมทดสอบไม่เพิ่มยอดจริง; ของขวัญแบบคอมโบนับเมื่อจบชุด

## เปิดเป็นเว็บไซต์
ต้องมี Node.js server ที่เปิดค้างเพื่อรับกิจกรรม TikTok; GitHub เก็บโค้ด ส่วน GitHub Pages ใช้รัน backend นี้ไม่ได้ ผู้ใช้ปลายทางเข้าเว็บ ไม่ต้องติดตั้งโปรแกรม/API key/OAuth

```sh
npm ci --ignore-scripts
npm start
```
เปิด http://localhost:3000 หรือใช้โฮสต์ Node.js เช่น Render ซึ่งมี `render.yaml` ให้แล้ว ตั้ง `PORT` ตามโฮสต์

ข้อมูลเก็บใน `DATA_DIR` (ค่าเริ่มต้น `./data`) หากใช้ Render free ข้อมูลบนดิสก์จะหายเมื่อ redeploy/restart และเว็บอาจพักเมื่อไม่ได้ใช้ ถ้าต้องเก็บรูป/เสียงข้ามการรีสตาร์ตต้องจัดพื้นที่ถาวรให้โฮสต์ก่อนใช้งานจริง ไฟล์ข้อมูลและความลับไม่ถูกส่งขึ้น GitHub

## ใช้งาน
1. เริ่ม TikTok LIVE ใส่ชื่อบัญชี และกดเชื่อมต่อ
2. กดเปิดเสียง; คงหน้าควบคุมไว้ตลอดไลฟ์
3. อัปโหลดรูป/เสียงและปรับวิดเจต
4. คัดลอก URL วิดเจตใส่ OBS Browser Source ขนาด 1920 × 1080
5. รับเสียงผ่าน Desktop Audio ของหน้าควบคุม; วิดเจตเป็นภาพอย่างเดียว

URL วิดเจตเป็นกุญแจห้อง ผู้ที่มีลิงก์จะเข้าถึงห้องได้ อย่าเผยแพร่ลิงก์นี้ในที่สาธารณะ การล้างคุกกี้จะสร้างห้องใหม่

## ข้อจำกัดของการเชื่อมต่อ
ใช้ `tiktok-live-connector` แบบไม่เป็นทางการ ซึ่งใช้บริการเซ็นการเชื่อมต่อภายนอก แม้ผู้ใช้ไม่ต้องกรอก API key แต่ไม่ได้หมายถึงไม่มีการเรียก API หรือไม่พึ่งบริการภายนอก การรับ LIVE อาจถูกจำกัดหรือหยุดทำงานเมื่อ TikTok/บริการเปลี่ยนระบบ ไม่มีการขอรหัสผ่าน TikTok หรือ OAuth

ยังไม่ได้ยืนยันการรับกิจกรรมจากไลฟ์จริงของเจ้าของบัญชี ต้องทดสอบขณะบัญชีเปิด LIVE อยู่ เสียงภาษาไทยขึ้นกับเสียงที่ระบบ/เบราว์เซอร์ติดตั้งอยู่
